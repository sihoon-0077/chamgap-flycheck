# 도면 생성 및 검수 기록

검수일: 2026-10-01

- A3 가로 PDF 8페이지 생성 완료. PDF 내 한국어 글꼴 포함 및 모든 페이지 텍스트 추출 확인.
- 각 페이지를 Poppler `pdftoppm -r 85 -png`로 렌더하고, 8페이지 전부 시각적으로 확인.
- 페이지 제목·도면 번호·한국어 표시·주석·치수·표·하단 경계에서 잘림이나 본문 겹침 없음.
- SVG 8개 모두 XML 구문 검사 통과. PDF와 동일한 생성 코드·좌표·문구 사용.
- 프레임 절단합계 12,240 mm 및 외형 800×400×1200 mm 원문 일치 확인.
- 제작 검토용 / 미실측, 핀맵 검토안, 절단안의 맞댐 가정, 정격 미확정 표시 확인.

Poppler가 사용자 경로의 한국어 때문에 일부 Bulgarian/Greek/Thai 보조 매핑 파일 경고를 출력했으나, 렌더링은 종료 코드 0으로 완료됐으며 한국어 PDF 글꼴과 페이지 출력은 정상이다.

이 기록은 문서의 출력 품질 검수다. 로드셀·기구 하중·센서 전압·전기 정격·펌프·차단·누수에 대한 실물 검수는 수행하지 않았다.
